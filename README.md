# 🪓 Timber Game

A simple 2D arcade game developed in **C++** using the **SFML** library, following the *Beginning C++ Game Programming* book by **John Horton**.

This project was built as part of my journey to learn **C++ game programming and game development fundamentals**.

The game challenges the player to chop a tree as quickly as possible while avoiding falling branches.

---

## 🎮 About the Game

The player controls a lumberjack standing next to a tree.

The goal is simple:

> **Chop the tree as fast as possible without getting hit by a branch.**

Every successful chop changes the position of the branches. The player must quickly move left or right to avoid them.

The game also includes a countdown timer, score system, animations, and sound effects.

## ▶️ How to Run

### Requirements

* Windows
* Visual Studio 2026
* C++ development tools
* SFML

### Running the Project

1. Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/timber.git
```

2. Open the Visual Studio solution/project.

3. Make sure the required SFML files and assets are available in the correct directories.

4. Select the appropriate build configuration.

5. Build the project.

6. Run the application.
